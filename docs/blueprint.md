# **App Name**: MBU Transport

## Core Features:

- User Authentication: Enable users to log in using email/password, Google, Facebook, or LinkedIn via Firebase Authentication.
- Auto Rickshaw Booking: Allow students to book auto rickshaws by specifying pickup/dropoff locations and number of seats.
- APSRTC Bus Schedules: Enable students to view bus schedules by specifying origin and destination.
- Live Tracking: Display real-time locations of buses and booked autos.
- Role-Based Access Control: Implement different user roles (student, student driver, admin) with associated permissions.
- Emergency SOS: Provide an emergency SOS button for students to request immediate assistance. Generate a canned message for help, incorporating user and location data to send via the user's installed messaging apps.
- Firestore Integration: Store and retrieve user, driver, auto, ride, and bus schedule data using Firestore collections.

## Style Guidelines:

- Primary color: Deep Blue (#1A237E) to evoke trust, safety, and reliability.
- Background color: Light Blue (#E3F2FD), a desaturated version of the primary color for a calm and clean backdrop.
- Accent color: Electric Purple (#8E24AA), a vibrant hue that highlights key CTAs.
- Body and headline font: 'Inter', a sans-serif typeface providing a modern and neutral feel suitable for headlines and body text.
- Use consistent, outlined icons representing transport, safety, and user roles.
- Employ a clean, split-screen layout for the login page with a clear signup CTA. Utilize card-based layouts for transport options and feature highlights.
- Subtle transition animations when navigating between pages and displaying real-time updates.
